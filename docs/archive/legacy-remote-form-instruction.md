# [АРХИВ] Инструкция по подключению прототипа оверлея Skald (v0.1.x)

> **Статус:** Архивный документ (2026-10-09).  
> **Контекст:** Инструкция описывает исходный исследовательский прототип с удалённой веб-формой ввода Skald.  
> Актуальная версия **QuickType** (начиная с `v0.2.x`) представляет собой полностью автономное двухоконное приложение с REST API / Webhook интеграцией.  
> См. актуальную документацию в [README.md](../../README.md) и [ADR 001](../decisions/001-two-window-rest-overlay-architecture.md).

---

Пошагово: от чистой Windows до формы ввода Skald поверх игры.
Прототип лежит в `quicktype-overlay/` репозитория.

Что должно получиться в итоге: в игре (без сворачивания) по хоткею
**Ctrl+Shift+F9** открывается форма ввода, текст уходит в Skald и
озвучивается, повторный хоткей прячет форму и возвращает фокус в игру.

---

## Шаг 0. Подготовить Skald

1. Запустите Skald.
2. В настройках включите input-сервер (он не стартует сам).
3. Проверьте в браузере: `http://127.0.0.1:10101/health` — должно
   ответить `{"status":"ok"}`.
4. Откройте `http://127.0.0.1:10101/overlay` — должна показаться форма.
   Если порт в настройках Skald не `10101`, см. раздел «Смена порта» ниже.

## Шаг 1. Установить клиент Overwolf

- Обычный клиент: https://download.overwolf.com/install/Download?Channel=website
- Или «Overwolf Developers Client» (тот же клиент на канале Developers):
  https://download.overwolf.com/install/Download?Channel=Developers

Если обычный клиент уже установлен, переключить его на канал Developers
(необязательно, но удобнее для разработки): Settings → About →
**Ctrl+Shift+ЛКМ** по логотипу Overwolf → в поле канала вписать
`Developers` → «Update and Relaunch».

## Шаг 2. Войти в аккаунт

Запустите клиент и войдите в аккаунт Overwolf (регистрация — по email).
Без входа загрузка расширения выдаёт ошибку «Unauthorized App».

## Шаг 3. Получить developer whitelist

Чтобы грузить unpacked-приложения, аккаунт должен быть в whitelist
разработчиков — это разовая процедура:

1. Зайдите на https://dev.overwolf.com/ тем же аккаунтом.
2. Следуйте «New Developer Onboarding» → отправьте **app proposal**
   (описание приложения; для прототипа достаточно описать обёртку:
   in-game оверлей с формой ввода текста для TTS).
   - «Application name» — рабочее название идеи, жёстких правил нет.
   - «Preferred Framework» — Plain JavaScript / None.
   - «Application category» — Tools & Utilities.
   - «Supported games» — без привязки: «All games / game-agnostic».
3. Дождитесь одобрения — по отзывам это занимает до нескольких дней.
   Пока аккаунт не в whitelist, «Load unpacked» не работает.

## Шаг 4. Загрузить расширение

1. ПКМ по клиенту Overwolf → **Packages**
   (или иконка гаечного ключа в доке → вкладка «About» →
   «Development Options»).
2. Нажмите **Development options**.
3. Нажмите **Load unpacked extension**.
4. Выберите папку `quicktype-overlay` (корень, где лежит `manifest.json`).

Приложение появится в доке Overwolf.

## Шаг 5. Запустить приложение

Кликните иконку приложения в доке. Оно фоновое: никаких окон не
откроется — это нормально. Приложение должно оставаться запущенным,
пока нужен хоткей.

## Шаг 6. Проверка на десктопе (smoke-тест)

Не запуская игру, нажмите **Ctrl+Shift+F9** — форма Skald должна
открыться в отдельном окне, ввод и Enter должны озвучиваться.
Повторный хоткей — окно скрылось.

## Шаг 7. Проверка в игре

1. Запустите игру в **borderless fullscreen** (для теста сойдёт любая
   оконная; игра должна определяться Overwolf).
2. Нажмите **Ctrl+Shift+F9** — форма поверх игры.
3. Введите текст, Enter — Skald озвучил.
4. Повторный хоткей — форма скрылась, фокус вернулся в игру.

---

## Диагностика

| Симптом | Причина | Что делать |
|---|---|---|
| «Unauthorized App» при загрузке/запуске | не вошли в аккаунт или аккаунт не в whitelist | войти в клиент; дождаться одобрения app proposal |
| Окно есть, но висит заглушка «Открываю форму…» | input-сервер не запущен | проверить `/health` |
| На десктопе работает, в игре окна нет | игра не определяется/не поддерживается Overwolf | попробовать оконную игру, borderless |
| Хоткей не реагирует | приложение не запущено или комбинация занята | запустить из дока; переназначить хоткей |
