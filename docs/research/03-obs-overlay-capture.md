# Проверка скрытия QuickType в OBS Studio

Обновлено: 2026-10-11. Отсутствие оверлея в записи нужно проверять на конкретной связке игры, графического API, Overwolf и OBS.

## Что подтверждено

В [официальной документации Game Capture](https://obsproject.com/kb/game-capture-source) есть настройка Capture third-party overlays. Её отключение — исходная настройка для попытки исключить сторонний оверлей. Это не универсальная гарантия приватности: [issue в официальном репозитории OBS](https://github.com/obsproject/obs-studio/issues/5630) описывает попадание оверлеев при выключенной опции. Порядок хуков и способ отрисовки могут влиять на результат.

## Режимы захвата

| Источник | Что проверить |
| --- | --- |
| Game Capture | Отключить Capture third-party overlays и проверить запись. |
| Window Capture (WGC) | Проверить запись: захват целевого окна не гарантирует исключение графики, уже нарисованной в его кадре. |
| Window Capture (BitBlt) | Проверить совместимость и наличие оверлея; результат зависит от приложения и метода захвата. |
| Display Capture | Захватывает изображение экрана; для исключения видимого оверлея этот режим не подходит. |

## Проверка перед трансляцией

1. Добавьте Game Capture и выберите окно игры.
2. Отключите Capture third-party overlays.
3. Проверьте, нет ли других активных источников, которые показывают тот же экран или игру.
4. Сделайте короткую локальную запись: откройте QuickType, введите неперсональный тестовый текст, отправьте его и скройте окно.
5. Просмотрите запись. Если текст виден, текущая связка не обеспечивает скрытие; смените настройки/источник и повторите тест.
6. Повторите проверку после обновления игры, OBS, драйвера или Overwolf и изменения графического режима.

Живой тест OBS в рамках исправлений 2026-10-11 не выполнялся. Утверждения о точном универсальном порядке наложения кадров не считаются подтверждёнными.
