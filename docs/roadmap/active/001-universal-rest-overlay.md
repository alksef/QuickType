# ROADMAP-001: QuickType — Универсальный REST Overlay для Overwolf App Store

## Цель

Создать полноценное автономное приложение **QuickType** для платформы Overwolf, позволяющее игрокам и стримерам отправлять произвольные REST API запросы через внутриигровой эксклюзивный оверлей по горячей клавише, с удобным десктопным интерфейсом конфигурации.

## Ключевые возможности

1. **Главное окно настроек (Desktop Window):**
   - Конфигурация REST эндпоинта (URL, HTTP-метод GET/POST/PUT).
   - Шаблонизатор полезной нагрузки (JSON template с плейсхолдером `{text}`).
   - Настройка HTTP-заголовков.
   - Изменение геометрии перетаскиванием в игре и сброс положения/размера.
   - Тестирование сетевого соединения с отображением HTTP-статуса и времени ответа.
   - Переназначение горячей клавиши через настройки Overwolf.

2. **Игровой оверлей (In-Game Overlay):**
   - Вызов по настраиваемому хоткею (`Ctrl+Shift+F9`).
   - Мгновенный захват клавиатурного ввода в Direct3D/Vulkan играх через Exclusive Mode.
   - Автоматический перевод фокуса в поле ввода.
   - Отправка по **Enter** с ожиданием HTTP 2xx и закрытием через 350 мс при включённой настройке; при ошибке текст сохраняется.
   - Скрытие по **Escape** при включённой настройке с сохранением черновика.

3. **Подготовка к Overwolf App Store:**
   - Подготовка к проверке гайдлайнов Overwolf: ow-native манифест, Desktop и In-Game окна, иконки; соответствие подтверждается отдельным ревью.
   - Упаковка в дистрибутивный архив (`QuickType-0.2.3.zip`).
